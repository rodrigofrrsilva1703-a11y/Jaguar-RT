# Jaguar × RTAV

PWA de estudo interno sobre a Reforma Tributária, desenvolvido para a Jaguar Assessoria Contábil a partir do evento RTAV — Reforma Tributária ao Vivo.

## Estrutura
- Estudos com comparação **Antes × Depois da Reforma**
- Casos práticos do RTAV
- Linha do tempo 2026–2033
- Calculadoras didáticas
- Fontes oficiais
- Layout responsivo e instalável como PWA

O site é estático e pode ser publicado gratuitamente pelo GitHub Pages.

Publicação automática: GitHub Pages a partir da branch `main`.
